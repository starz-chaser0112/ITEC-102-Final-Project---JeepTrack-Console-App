JeepTrack: Jeepney Fare Guide for Commuters

JeepTrack is console app that provides estimated fare of traditional jeeps for the commuter to be informed of the possible amount they need to pay from one location to another. 

The objective of this console app is to provide an estimated fare for traditional jeepneys and displaying the information of the route including estimated time arrival and distance.
