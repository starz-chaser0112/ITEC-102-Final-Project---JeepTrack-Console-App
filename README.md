# JeepTrack
### Jeepney Fare Guide for Commuters

## DESCRIPTION
JeepTrack is a console-based application that aims to provide the estimated fare price for commuters who uses traditional jeepneys as transportation. Furthermore, it also includes the route details based on their current location and desired destination consisting of estimated travel time and distance. It also allows you to identify yourself to check for possible discount eligibility if you're a students, senior citizen or person with disaabilities.

## OBJECTIVES
- To provide estimated fare price of traditional jeepney to commuters
- To compute the fare price for regular and discounter passenger
- To display the information of the travel
- To help commuters to identify transportation expenses before traveling

## PROGRAM FEATURES 
- **Selecting Locations**: Prompting user to enter their current location and destination, while also allowing them to quit the program by entering "exit."
- **Calculating Fare**: Calculating the fare for regular passenger and discounted passengers.
- **Validating Availability of Inputs**: Validating if the user inputs for location, passenger type and routes are available.
- **Validating Inputs**: Allowing user to enter new value if first inputs is invalid.
- **Route Information**: Displaying route information including fare amount, route, discount amount, passenger type, distance and estimated travel time.
- **Identifying Errors**: Informing user if their input is invalid by displaying error message.
## COMPILING AND RUNNING THE PROGRAM
**Prerequisite**
- Visual Studio Code or any integrated development environment compatible with C#
- Install .NET SDK  
**Visual Studio Code**
1. Download or clone the repository
2. Open project folder in Visual Studio Code
3. Open new integrated terminal
4. Compile and build the application using `dotnet build`
5. run the application using: `dotnet run`
